# PrepFlow ユーザー視点 ASCII 画面一覧

目的: 実装済みの画面と sheet を、ユーザーが触る順番で「1画面1枚」に並べる。

このファイルは UI の正本ではない。正本は `docs/ui-fidelity-contract.md`、`design/`、snapshot、`docs/ui-comparisons/` とする。各画面の部品名と配置は `docs/ascii-wireframes.md` と揃える。

## 00. 全体動線

```text
+--------------------------------------------------------------------------------+
| 未認証                                                                         |
|  AuthGateView                                                                  |
|      | サインイン / SQLite 縮退                                                |
|      v                                                                         |
| 初回体験                                                                       |
|  ActivationSummaryView -> SimulationView -> ServiceSetupView -> Board Now      |
|                                                                                |
| 日次運用                                                                       |
|  Board Now <-> Board Dishes <-> Board Staff                                    |
|      |                 |                 |                                    |
|      |                 |                 +-> SettingsHomeView                 |
|      |                 +-> LabelOpsSheet                                      |
|      +-> NowGuidanceSheet                                                     |
|                                                                                |
| 周辺運用                                                                       |
|  SimulationView -> CloseLoopSheet -> ReservationHubSheet                       |
|                                      |                                         |
|                                      +-> DirectBookingOpsSheet                 |
|                                      +-> ServicePassOpsSheet                   |
|                                                                                |
| 設定/編集                                                                      |
|  SettingsHomeView -> ServiceSetupView / CatalogEditorView / SimulationView     |
+--------------------------------------------------------------------------------+
```

## 18. 戻りと分岐

```text
+--------------------------------------------------------------------------------+
| よく使う戻り                                                                   |
|                                                                                |
| SettingsHomeView -> Board Now                                                  |
| CatalogEditorView -> Board Now                                                 |
| SimulationView -> Board Now                                                    |
| CloseLoopSheet -> ReservationHubSheet -> Board Now                             |
| ServiceSetupView -> Board Now                                                  |
|                                                                                |
| 分岐の扱い                                                                     |
|                                                                                |
| - 主要画面は AuthenticatedSessionView の screen state で切替                   |
| - Board 内の3ビューは BoardTopBar の segmented control で切替                  |
| - sheet は操作完了後に親画面へ戻る                                             |
+--------------------------------------------------------------------------------+
```
